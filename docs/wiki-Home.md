# PhoneMic —— 把手机当作电脑麦克风

## 这是什么

PhoneMic 是一个小工具，它把**手机的麦克风实时送到电脑上**，让电脑把它当成一个正常的麦克风使用。

装好之后，你在微信、QQ、腾讯会议、Zoom、Discord、OBS 或任何语音软件里，看到的输入设备会多出一个 `CABLE Output`。选中它，你说话的声音就来自手机。

## 它解决什么问题

很多场景下，电脑自带的麦克风不够用：

- **台式机没有麦克风。** 主机没有内置麦克风，插耳机又嫌线短，手边只有一部手机。
- **笔记本麦克风太远。** 麦克风在键盘边上，坐在沙发上录音，声音又小又空。
- **想在房间另一头录音。** 手机可以放在任何地方，电脑放在桌上。
- **临时开个会，不想买设备。** 不用买 USB 麦克风，也不用再装一个专门的硬件。
- **手机的音质比电脑好。** 现在的手机普遍有双麦克风和降噪，比廉价笔记本麦克风清楚得多。

换一种说法：**你手上已经有一支不错的麦克风，就是你的手机。这个项目负责把这支麦克风接进电脑。**

## 为什么需要它（而不是直接连蓝牙）

手机通过蓝牙连电脑时确实会暴露成一个音频输入设备，但那是「免提通话」通道，采样率通常只有 8–16 kHz，声音发闷、有明显压缩，用来开会勉强，用来录音不行。

PhoneMic 走的是局域网 Wi-Fi，传输 **48 kHz 单声道 16 bit** 的原始音频，带宽约 96 KB/s，音质接近手机原生录音，延迟在 100 ms 以内。

## 工作原理

```
 手机麦克风
     │  AudioRecord：48 kHz / 单声道 / PCM 16 bit
     │  每 10 ms 一包，UDP 发送
     ▼
 电脑：PhoneMicServer.exe
     │  抖动缓冲 60 ms + 乱序重排
     ▼
 VB-Audio "CABLE Input"（虚拟声卡）
     │
     ▼
 CABLE Output  ←—— 在微信 / Zoom / OBS 里选它当麦克风
```

### 为什么必须先装 VB-Audio Virtual Cable

Windows 不允许普通程序凭空创建一个音频输入设备——那需要经过数字签名的内核驱动。所以「虚拟麦克风」这件事本身一定有一个驱动参与，所有同类工具（WO Mic、DroidCam 的麦克风模式）都是这么做的。

PhoneMic 不重复造驱动，而是复用免费成熟的 VB-Audio Virtual Cable：程序把声音**播放**进 `CABLE Input`，系统和其它软件就把 `CABLE Output` 当作一个麦克风。

**少了这一步，程序只会把手机的声音从音箱里放出来，不会出现在任何软件的麦克风列表里。** 这是使用时最容易踩的坑，请务必先装。

## 支持哪些软件

只要是 Windows 上能选麦克风的软件都可以，常见的有：

| 类别 | 例子 |
|---|---|
| 会议 | 腾讯会议、Zoom、钉钉、飞书、Teams |
| 语音 | Discord、YY、TeamSpeak |
| 社交 | 微信、QQ |
| 直播 / 录制 | OBS、Streamlabs、Audacity |
| 游戏 | 绝大多数支持语音的游戏 |

在这些软件里，把**麦克风**选成 `CABLE Output`，把**扬声器**保持你原来的设备（不要选 CABLE），这样既能听又不会互相串音。

## 系统要求

| 端 | 要求 |
|---|---|
| 电脑 | Windows 10 / 11，64 位 |
| 手机 | Android 7.0（API 24）及以上 |
| 网络 | 两端在同一个 Wi-Fi 局域网 |
| 额外软件 | VB-Audio Virtual Cable（免费） |

不需要 .NET 运行时（exe 已自带），不需要 root，不需要公网服务器。

## 三步开始用

1. **电脑**：装好 VB-Audio Virtual Cable 并重启 → 双击 `PhoneMicServer.exe` → 记下窗口里打印的 IP 和端口。
2. **手机**：装 `PhoneMic.apk` → 填 IP 和端口 8765 → 点「开始」→ 允许麦克风权限。
3. **使用**：在微信 / Zoom / OBS 里把麦克风选成 `CABLE Output`。

两个文件都在仓库的 **Releases** 页面下载，由 GitHub Actions 自动构建。

## 隐私说明

- 音频**只在你的局域网内**从手机传到电脑，不经过任何服务器，也不上传云端。
- 程序不做录音、不落盘、不做统计上报。
- 电脑端只监听本机的 UDP 端口，收到的数据直接送进声卡，用完即丢。

## 已知限制

- 只支持同一局域网，没有做公网穿透；在外面用需要自己搭内网穿透（如 Tailscale）。
- 只传麦克风，不传电脑的系统声音（反向功能不在此项目范围内）。
- 没有回声消除：如果电脑用音箱外放，对方可能听到回声，建议戴耳机。
- APK 是 debug 签名，因为把 release 密钥放进公开仓库不安全；长期自用请用自己的密钥重新签名。
- 部分国产手机的省电策略会杀掉后台服务，需要在设置里把 PhoneMic 的电池策略改为「不限制」。
