# PhoneMic

**把手机当成电脑的麦克风。** 手机负责采集，电脑负责降噪后播放到一个虚拟音频设备，于是微信、QQ、Zoom、Discord、OBS、游戏语音里都能把手机当作麦克风使用。

- 电脑端：`PhoneMicServer.exe`（Windows 10/11，带图形界面的单文件程序，无需安装 .NET）
- 手机端：`PhoneMic.apk`（Android 7.0 及以上）

两者都在 [Releases](../../releases) 里，由 GitHub Actions 自动构建。

**当前版本：v1.2**

## 它是怎么工作的

```
 手机麦克风 ──► AudioRecord 48kHz 单声道 PCM16（回声消除）
                        │
                        │  UDP，每 10 ms 一个包
                        ▼
             PhoneMicServer.exe
                        │  抖动缓冲 + 重排序
                        │  降噪：80 Hz 高通 → 自适应噪声门
                        ▼
              VB-Audio "CABLE Input"
                        │
                        ▼
        CABLE Output ＝ 系统里的一个麦克风
```

### 为什么必须装 VB-Audio Virtual Cable

Windows 不允许普通程序凭空创建一个音频输入设备，那需要经过签名的内核驱动。所以「虚拟麦克风」这件事本身一定有驱动参与。

本项目的做法是不重复造驱动，而是复用免费成熟的 **VB-Audio Virtual Cable**：程序把声音播放进 `CABLE Input`，系统和其它软件就把 `CABLE Output` 当成一个麦克风。少了这一步，声音只会从音箱放出来。

## 快速开始

### 1. 电脑端

1. 安装 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)，装完重启一次。
2. 从 [Releases](../../releases) 下载 `PhoneMicServer.exe`，双击运行。
3. 窗口会自动选中 `CABLE Input`，面板上也会显示本机 IP。
4. 点「开始」，保持窗口开着。

### 2. 手机端

1. 安装 `PhoneMic.apk`（第一次安装需要允许「安装未知来源应用」）。
2. 手机和电脑连同一个局域网（有线网 + Wi-Fi 也算，只要在同一个路由器下）。
3. 填入电脑上显示的 IP 和端口 `8765`，点「开始」。
4. 允许麦克风权限和通知权限。

### 3. 在其它软件里选用

把**麦克风**选成 `CABLE Output (VB-Audio Virtual Cable)`。**不要**选 `CABLE Input`，那是播放端写入的方向。

| 区域 | 作用 |
|---|---|
| 输出设备 | 自动选中名字含 `CABLE Input` 的设备；不是虚拟声卡时会弹窗提醒 |

| 日志 | 设备选择结果与错误原因 |

## 降噪与点击声抑制

风扇噪音分两类：低频轰鸣和宽带气流声。处理分两级：

1. **80 Hz 二阶高通**：切掉低频轰鸣，人声基频不受影响。
2. **自适应噪声门**：跟踪最近的「最安静电平」作为噪声底，门限设在底噪之上 4–14 dB。低于门限压到 −30 dB，高于门限正常放行，增益逐采样平滑。

**鼠标点击声**是 1–5 ms 的瞬态脉冲。v1.2 给噪声门加了 12 ms 起音保持——脉冲必须持续超过门限 12 ms 才允许开门，所以它还来不及被放大就已经结束了。人说话远超 12 ms，不受影响。

**局限**：如果点击正好发生在你说话的同时（门本来就开着），它仍会被录进去；要处理那种情况需要频谱处理。降噪也不是频谱降噪或 AI 降噪，说话的同时底噪仍在。

## 协议说明

每个 UDP 包 = 16 字节头 + 960 字节 PCM，正好 10 ms 音频。

| 偏移 | 长度 | 含义 |
|---|---|---|
| 0 | 4 | 魔数 `PMIC`（小端 `0x43494D50`） |
| 4 | 4 | 序号，uint32 |
| 8 | 8 | 发送端单调时钟，毫秒 |
| 16 | 960 | PCM S16LE，48000 Hz，单声道 |

选 UDP 而不是 TCP：TCP 的重传会造成队头阻塞，延迟越积越大；语音要的是稳定可预测的延迟。

## 常见问题

**手机连不上电脑**

- 确认在同一局域网。**电脑插网线、手机连这个路由器的 Wi-Fi，也是同一个局域网。**
- Windows 防火墙要允许**专用网络**。
- 多网卡或 VPN 时，选和手机同网段的那个 IP。

**语音软件里没有麦克风**

- 没装 VB-Audio Virtual Cable，或装完没重启。

**延迟偏高 / 断断续续**

- 把「缓冲」调大到 60–150 ms。
- 关掉手机省电模式；尽量用 5 GHz Wi-Fi。

**听到自己说话**

- 输出设备选成了音箱或耳机。选回 `CABLE Input`。

**手机锁屏后停止**

- 把 PhoneMic 的电池策略设为「不限制」。

## 已知限制

- 只支持同一个局域网，没有做公网穿透。
- 降噪是滤波 + 噪声门，不是频谱或 AI 降噪。
- APK 使用 debug 签名，长期自用请用自己的密钥重新签名。
- 只传麦克风，不传系统声音。
- 没有回声消除以外的声学处理；外放时建议戴耳机。
