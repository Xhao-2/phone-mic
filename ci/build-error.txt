# 构建日志捕获（仅在 Android job 失败时写入）

上一次失败的原因已经修掉了：

    StreamService.java:153: error: cannot find symbol
      symbol:   variable PERFORMANCE_MODE_LOW_LATENCY
      location: class AudioRecord

`AudioRecord` 上没有这个常量，v1.2.17 起已移除该调用。

这个文件由 `.github/workflows/build.yml` 里的 “Capture build log on failure” 步骤在失败时覆盖写入，
用于在 Actions 日志界面无法渲染时排查编译错误。构建正常时它不会被改动。
